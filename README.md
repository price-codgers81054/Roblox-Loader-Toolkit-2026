## FAQ

### What are the system requirements?

XCutors requires a Windows 10 or 11 operating system. A modern CPU and stable internet connection are recommended for optimal performance.

### Is this a single program or multiple separate tools?

XCutors is a collection packaged with a universal loader. The loader manages and allows you to launch several different executor engines from one location.

### How often is the collection updated?

Updates are issued on a semi-regular basis to address compatibility issues with Roblox updates and to potentially include new executor versions.

### Can I use these tools on a Mac or Linux?

No, this package is designed exclusively for Windows desktop systems. The underlying executors are built for and only run on Windows.

### What script types are supported?

XCutors are designed to execute Lua scripts written for the Roblox platform. This includes UI scripts, automation tools, and various gameplay modifications.

### Why do I need a password to extract the files?

A simple password is used during extraction as a basic measure against automated scanning and to ensure intentional distribution of the package.

### Do I need to turn off my anticomponent software?

Some security software may flag script executors as false positives due to their injection capabilities. You may need to create an exclusion for the XCutors folder.
